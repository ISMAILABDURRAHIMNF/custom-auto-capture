# Custom Auto Capture

Hi, this repo is just tiny project, custom auto screen capture using selenium with Chrome web driver. Makesure Chrome is installed on your computer, or u could change the webdriver in `app.py`.

## 🔧 How to use

Clone this repo to ur computer

```bash
  git clone https://github.com/ISMAILABDURRAHIMNF/custom-auto-capture.git
```

Install all required modul using `pip` to file `requirements.txt`

```bash
  pip install -r requirements.txt
```

Create `websites.txt` file, list all the websites you want to capture images from.

```bash
  web1.com
  web2.com
  web3.com
  ...
```

Run the program

```bash
  python app.py
```
