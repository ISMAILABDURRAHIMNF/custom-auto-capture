# Custom Auto Capture

Hi, this repo is just tiny project, custom auto screen capture using selenium with Chrome web driver. Makesure Chrome is installed on your computer, or u could change web driver.

## 🔧 How to use

Clone this repo to ur computer

```bash
  git clone https://github.com/ISMAILABDURRAHIMNF/custom-auto-capture.git
```

Install all required modul using `pip` to file `requirements.txt`

```bash
  pip install -r requirements.txt
```

Run the program

```bash
  python app.py
```

## ❗Warning !

This project is under development, makesure Chrome is installed on ur computer if u not change webdriver!!!
